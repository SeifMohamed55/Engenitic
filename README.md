# Engenitic

**Engenitic** is a modern, responsive English-language web platform designed to enhance language learning and AI-powered interactions. Built with **Angular** and **.NET Core**, it follows **Clean Architecture principles** to ensure scalability, maintainability, and high code quality.

---

## Key Highlights

- **Cloud-hosted PostgreSQL** for reliable data storage.
- **JWT authentication** for secure access.
- **Efficient image and video handling** via FormData.
- **Responsive UI/UX** across all devices using Tailwind CSS + SCSS.
- **Integrated ngx libraries** for toasts, loaders, charts, and carousels.
- **Three AI-powered models**:
  - Grammar Correction
  - Question-Answering
  - Text-to-Speech Generation
- **Subscription system** with secure data handling.

---

## Features
